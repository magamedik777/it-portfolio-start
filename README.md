it-portfolio-start

Учебный проект, в разработке.

Название и цель

Учебное портфолио начинающего тестировщика (junior QA). Показывает, как я проверяю веб-приложение: пишу тест-кейсы и оформляю баги. Предназначено для того, кто выбирает стажёра на позицию QA.

Планируемый результат

Читатель увидит два проекта: (1) 15 тест-кейсов и баг-репорты для формы входа на открытом демо-сайте; (2) тест-план, чек-лист и тест-кейсы для сценария покупки в демо-магазине, с итоговой таблицей результатов.

Моя роль

Всё выполняю лично: пишу тест-кейсы, выполняю проверки, оформляю дефекты. Показываю навыки: тест-дизайн, баг-репорты, работа с DevTools.

План работы
Подготовить структуру репозитория и профиль GitHub (сделано/в процессе).
Выполнить Проект 1 (форма входа).
Начать Проект 2 (тест-план и чек-лист). Статус: в разработке; готовых результатов пока нет.
Проверка результата

Любой человек может открыть файл test-cases, повторить шаги кейса на демо-сайте и сравнить с ожидаемым результатом; баги воспроизводятся по шагам из bug-reports.
